## 📌 Project Overview

Movie Analytics is a data analytics project developed using Microsoft Power BI to explore movie industry performance through box office revenue, production budgets, IMDb ratings, genres, release years, countries, and opening-week performance.

The project focuses on transforming movie data into meaningful insights through data cleaning, data transformation, exploratory data analysis, KPI development, and interactive dashboard visualization.

## 🎯 Project Objectives

- Analyze worldwide box office revenue and movie production budgets.
- Explore movie releases and trends over time.
- Compare box office performance across genres.
- Analyze country-wise box office revenue.
- Identify top-performing movies and collections.
- Evaluate the relationship between production budget and box office revenue.
- Compare opening-day and first-week sales performance.
- Monitor average IMDb ratings and movie counts.

## 🎛️ Interactive Filters

The dashboard includes the following slicers:

- **Country:** Explore movie performance by country.
- **Genre:** Compare different movie genres.
- **ReleaseYear:** Analyze movies released in different years.

These filters allow users to explore different segments of the movie industry interactively.
