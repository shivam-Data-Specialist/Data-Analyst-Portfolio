# 📊 Sales Performance Dashboard | Power BI

## 📌 Project Overview
An interactive Power BI dashboard designed to analyze sales performance, product profitability, monthly trends, and category-wise sales distribution.

- **Total Sales:** 2.30M

## 📊 Key Features
- Top 3 products by sales and profit
- Monthly sales trend analysis
- Product cost vs. sales comparison
- Category-wise sales and profit analysis
- State-wise sales visualization
- Interactive month and year filters
